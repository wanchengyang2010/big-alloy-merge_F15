Full mode is the flagship experience of Big Alloy Merge: seventeen elements arranged in a single fusion chain, from the tiny 西西 🕴️ all the way up to the legendary 钇钾 🪙. Each element has its own personality — a unique emoji, a base radius that determines how much space it takes up in the container, a point value you earn the moment you merge it into existence, and a short message that flashes on screen when the merge fires. This page is your complete reference for all seventeen.

## Drop Sequence

Every Full mode game begins with a fixed opening sequence before the drop pool goes random. This sequence ensures you always have a gentle ramp into the chain:

**Fixed opening (in order):**
西西 → 西西 → 张骞 → 党项 → 党项 → 蟑螂 → 西西 → 张骞 → 党项 → 蟑螂 → 仓鼠 → 灰鼠

After those twelve drops, the game draws randomly from **tiers 0–5** (西西 through 灰鼠) with equal probability.

## Dynamic Drop System

Full mode features the Dynamic Drop System introduced in v2.3.0.0. As you merge your way up the chain, the game gradually unlocks higher tiers for random drops — keeping the late game engaging and the stakes higher.

<Note>
The unlock rule is: **merging to tier N unlocks tier N−2 for future drops**, subject to rate limiting. For example, once you merge up to tier 8 (考拉), tier 6 (家畜) becomes eligible to appear in drops. Tier N−2 elements are rate-limited to once every 8 drops, and tier N−3 elements to once every 5 drops. See [Dynamic Drop System](/reference/dynamic-drop) in the Reference section for full details.
</Note>

## Scoring Notes

You earn points equal to the **score value of the element you just created**. Merging two 西西 (tier 0) produces a 张骞 (tier 1) and awards you **3 points** — the score of 张骞, not of 西西. Chain reactions score each individual merge separately.

钇钾 🪙 is the crown jewel at **200 points**, but reaching it requires merging two 锐哥 (tier 15, worth 136 each) — those two merges alone already demand a fully packed container of high-tier elements beneath them. The path to 钇钾 is what Full mode is all about.
