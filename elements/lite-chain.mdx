Lite mode is the recommended starting point for new players, and it uses a self-contained 12-element chain that is entirely independent from the Full mode chain. You begin with 灰鼠 🐁 as the smallest droppable element and work your way up to 钇钾 🪙 — the same ultimate prize, but reached through a shorter and more approachable sequence. Because Lite mode uses its own radius and score values, the numbers you see here will differ from anything you read on the Full Chain page, even for elements that share a name.

## Drop Sequence

Every Lite mode game opens with a short fixed sequence to ease you into the chain:

**Fixed opening (in order):**
灰鼠 → 灰鼠 → 家畜 → 猴子 → 猴子 → 考拉

After those six opening drops, the game draws randomly from **tiers 0–5** (灰鼠 through 阳阳) with equal probability for the rest of the session.

<Info>
Lite mode does **not** have the Dynamic Drop System. The droppable pool stays fixed at tiers 0–5 (灰鼠 through 阳阳) for the entire game, regardless of how high you merge. This keeps the difficulty curve predictable and makes Lite mode the ideal setting for learning the fundamentals.
</Info>

## Scoring Notes

As with all modes, you score the **point value of the element you create** — not of the two elements that fused. Every merge in a chain reaction scores individually.

Because the Lite chain is shorter, the point values are intentionally scaled up. 钇钾 🪙 in Lite mode is worth **280 points**, compared to 200 in Full mode. This reflects the compressed chain length and rewards players who push all the way to the top in a more constrained environment.

## Independent Parameters

Lite mode's ball parameters are tuned separately from Full mode. A few things to keep in mind:

- **Radii differ** — 灰鼠 starts at radius 18 in Lite mode (the smallest), while in Full mode the same element sits at radius 50 (tier 5 out of 17). The physical behaviour you learn in Lite transfers to Full, but the spacing and stacking dynamics feel distinct.
- **Scores differ** — Lite scores are higher per element to compensate for the shorter chain. The cumulative score potential is different between modes.
- **Container size** — Lite mode uses a narrower reference container (480 px wide) vs Full mode (540 px wide), so the same physical play style will feel slightly tighter.

If you are moving from Lite to Full mode, expect to drop smaller elements more often and plan further ahead for the upper tiers.
