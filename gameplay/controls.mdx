Big Alloy Merge is designed to be picked up in seconds: one drag, one release, one merge. Whether you are using a mouse on a desktop, a finger on a touchscreen, or prefer to navigate by keyboard, every interaction maps to the same fundamental drop-and-merge loop. This page covers every input method so you can stay focused on the stack instead of searching for the right button.

## Mouse and Touchscreen

The drop mechanic works identically with a mouse and on a touchscreen — press, drag to position, release.

| Action | Method |
|--------|--------|
| Move preview | Hover the mouse inside the container — the preview ball follows your cursor horizontally |
| Drop ball | Click and hold inside the container, drag to your chosen position, then release |
| Adjust position | While holding before release, slide left or right to fine-tune where the ball will land |
| Click buttons | Click any button in the top button bar |

<Note>
  Touchscreen input is supported natively. The same drag-and-release mechanic applies with your finger or stylus — press inside the container, drag to position, and lift to drop. No special mode or setting is required.
</Note>

## Keyboard Shortcuts

Use these keys at any time during gameplay or on the mode-select screen.

| Key | Action |
|-----|--------|
| `B` | Enter Lite mode (12-element chain, recommended for new players) |
| `A` | Enter Full mode (17-element chain, dynamic drops) |
| `C` | Enter Debug mode (password required: **3919**) |
| `D` | Enter Demo mode (AI autoplay — sit back and watch) |
| `Q` | Enter Q Self mode (custom images, names, and merge messages) |
| `R` | Restart the current game from scratch |
| `F11` | Toggle true fullscreen / windowed mode |
| `F3` | Toggle the debug panel (Debug and Full Debug modes only) |
| `ESC` | Exit the game (returns to mode select or closes the window) |

## Button Bar

The top button bar runs across the top of the game window. Buttons are always visible during gameplay and are listed here from left to right.

| Button | Function |
|--------|----------|
| 🔄 Restart | Restart the current game immediately |
| 🔲 Maximize | Maximize the window without covering the taskbar |
| ⬜ Fullscreen | Toggle true fullscreen — equivalent to `F11` |
| ━ Minimize | Minimize the window to the taskbar |
| 🐛 Debug | Toggle the debug panel (visible in Debug and Full Debug modes only) |
| 🏠 Menu | Return to the mode select screen |
| ❌ Exit | Quit the game entirely |

<Note>
  The **🔊 / 🔇 sound toggle** is a separate circular button rendered in the top-right corner of the game window — it is not part of the left-to-right button bar. Click it to mute or unmute all music and sound effects at any time.
</Note>

<Tip>
  Use **🔲 Maximize** rather than dragging the window border if you want the game to fill your screen while keeping the taskbar accessible. For a fully immersive experience with no taskbar overlap, use **⬜ Fullscreen** or press `F11` instead.
</Tip>
